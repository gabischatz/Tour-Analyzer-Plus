# OpenStreetMap-Hinweis

Tour Analyzer Plus kann Daten aus OpenStreetMap anzeigen, auswerten oder für die manuelle Prüfung vorbereiten.

## Namensnennung

Bei Verwendung von OpenStreetMap-Daten ist folgende Namensnennung erforderlich:

```txt
© OpenStreetMap-Mitwirkende
```

## Lizenz der OSM-Daten

OpenStreetMap-Daten stehen unter der:

```txt
Open Database License (ODbL) 1.0
```

## Wichtig

Tour Analyzer Plus ist kein offizielles OpenStreetMap-Projekt.

Das Programm dient nur zur Analyse und Vorbereitung.  
Änderungen an OpenStreetMap-Daten müssen immer manuell geprüft und mit geeigneten Werkzeugen wie JOSM hochgeladen werden.
